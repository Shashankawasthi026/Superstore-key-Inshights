# Superstore Business Intelligence Dashboard

## Project Overview
This project analyzes Superstore sales data using SQL, Excel, and Power BI.

## Objectives
- Monthly Sales Analysis
- Growth Rate Calculation
- Customer Segmentation
- Category Performance Analysis
- Regional Profitability Analysis
- Executive Dashboard Creation

## Tools Used
- SQL
- Microsoft Excel
- Power BI

## Key KPIs
- Total Sales
- Total Profit
- Profit Margin
- Total Customers
- Sales Growth %

## Dashboard Features
- Monthly Sales Trend
- Sales by Region
- Profit by Category
- Segment Contribution
- Top Customers Analysis
- Interactive Filters

## Files Included
- SQL Analysis Script
- Excel Analysis Workbook
- Power BI Dashboard
- Business Analysis Report

## Business Insights
- Technology category generated the highest profit.
- Consumer segment contributed the highest revenue.
- Discounting impacts profit margins.
- Regional performance varies across locations.
